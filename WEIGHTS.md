# Model Weights

Pretrained weights and experiment checkpoints are not stored in this
repository. Pass their local paths to the public entry scripts at runtime.

## Official Pretrained Weights

| Model | Expected checkpoint | Official source |
| --- | --- | --- |
| U-Net | ResNet-50 ImageNet encoder weights | Downloaded automatically by `segmentation_models_pytorch` when `encoder_weights="imagenet"` |
| DeepLabV3+ | ResNet-50 ImageNet encoder weights | Downloaded automatically by `segmentation_models_pytorch` when `encoder_weights="imagenet"` |
| SegFormer | `mit_b0_20220624-7e0fe6dd.pth` | [OpenMMLab download](https://download.openmmlab.com/mmsegmentation/v0.5/pretrain/segformer/mit_b0_20220624-7e0fe6dd.pth) |
| Swin-Unet | `swin_tiny_patch4_window7_224.pth` | [Swin-Unet authors' Google Drive folder](https://drive.google.com/drive/folders/1UC3XOoezeum0uck4KBVGa8osahs6rKUY?usp=sharing) |
| MatSAM | `sam_vit_h_4b8939.pth` | [Meta SAM ViT-H download](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth) |
| HQ-SAM | `sam_hq_vit_b.pth` | [HQ-SAM ViT-B download](https://drive.google.com/file/d/11yExZLOve38kRZPfRx_MRxfIAKmfMY47/view?usp=sharing) or [officially linked Hugging Face mirror](https://huggingface.co/lkeab/hq-sam/resolve/main/sam_hq_vit_b.pth) |
| SAM2 | `sam2.1_hiera_base_plus.pt` | [Meta SAM2.1 Base+ download](https://dl.fbaipublicfiles.com/segment_anything_2/092824/sam2.1_hiera_base_plus.pt) |
| micro-sam | `vit_b_lm` | Downloaded automatically by `micro_sam.util.get_sam_model`; [BioImage.IO checkpoint](https://uk1s3.embassy.ebi.ac.uk/public-datasets/bioimage.io/diplomatic-bug/1.2/files/vit_b.pt) |

The SAM2 scripts use
`configs/sam2.1/sam2.1_hiera_b+.yaml`; do not substitute a checkpoint from a
different SAM2 architecture without also changing the config.

The micro-sam checkpoint can be downloaded into its normal cache before
running an experiment:

```bash
python -c "from micro_sam.util import get_sam_model; get_sam_model(model_type='vit_b_lm')"
```

## Fine-Tuned Checkpoints

Fine-tuned checkpoints for the evaluated model-dataset combinations will be
available from the following Hugging Face model collection upon publication:

- [Segmentation methods for quantitative microstructure analysis](https://huggingface.co/collections/WUT-AI-AI4Mat/segmentation-methods-for-quantitative-microstructure-analysi)

The model collection is currently private and will be made publicly
accessible upon publication.

Binary LoRA+decoder fine-tuning for Aachen-Heerlen, EMPS, and Grain produces:

```text
matsam_lora_decoder_best.pth
hqsam_lora_decoder_best.pth
sam2_lora_decoder_best.pth
microsam_lora_decoder_best.pth
```

These files contain only the trainable LoRA and mask-decoder parameters. Load
them together with the official base checkpoint through the corresponding
`test_lora_decoder.py` script.

Class-token fine-tuning for EBC, Super, MetalDAM, and UHCS produces:

```text
semantic_matsam_best.pth
semantic_hqsam_best.pth
semantic_sam2_best.pth
semantic_microsam_best.pth
```

These files additionally contain the learned class-token parameters and must
be loaded through the corresponding `test_semantic_*.py` script.

CNN and Swin-Unet training scripts save their best model in the selected
output directory. SegFormer checkpoints are generated by MMSegmentation under
its configured work directory.

Until the model collection is public, reproduce these checkpoints by running
the corresponding training scripts. Each checkpoint must be loaded with the
matching architecture, dataset class count, and test entry point described in
`REPRODUCTION.md`.

## Suggested Local Layout

The exact location is user-defined because every public script accepts a
checkpoint path. A consistent local layout is:

```text
weights/
├── pretrained/
└── finetuned/
```

Files matching `*.pth`, `*.pt`, `*.ckpt`, `*.safetensors`, and `*.onnx` are
ignored by Git.
